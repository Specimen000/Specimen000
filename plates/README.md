# plates

The visual record. Every animated plate is rendered by `tools/render_plates.py`
from `000_specimen.png` and `ledger/simulated/`. Two inks, sampled from the
photograph: `#0B0A09` and `#E2D8C6`. Thirty-two shades between them. Nothing else.

```

001_attach.gif            terminal attaching to the enclosure

004_convergence.gif       observations becoming a conclusion
005_progression.gif       the experiment as a trace

007_manifest.gif          the output manifest, sealed
008_pending.gif           last plate
```
